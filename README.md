# Baset Prokousholi Ltd.

Responsive company website for Baset Prokousholi Ltd., with services, filterable project portfolio, project details, and contact options.

## Website files

- `index.html`: company copy, sections, project cards and contact details.
- `styles.css`: desktop and mobile layout.
- `site.js`: mobile navigation, project filters, accessible dialogs and email draft preparation.
- `assets/`: original architectural illustrations and a proposed brand monogram.
- `.nojekyll`: serves the site directly with GitHub Pages.

There is no build step, framework installation or external asset dependency.

## Publishing

GitHub repository Settings → Pages → Build and deployment:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Pushing to `main` updates the published website. No custom domain is configured.

## Contact behaviour

The enquiry form opens a draft in the visitor’s email application for review and sending. The website does not submit or store personal data.
